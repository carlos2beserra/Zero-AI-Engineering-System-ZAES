# MAES v1.1.3

**Data:** 2026-06-05
**Tipo:** patch — correções na documentação web (Fumadocs). **Sem mudança de comportamento do CLI.**

## 🐛 Correções

### Busca da documentação voltou a funcionar

O site de docs usa `output: "export"` (HTML estático), mas o backend de busca do
Fumadocs nunca havia sido configurado — toda busca retornava vazio.

- Adicionada a rota estática `web/src/app/api/search/route.ts`
  (`staticGET` + `export const revalidate = false`), que emite o índice de busca
  Orama como JSON no momento do build.
- O `RootProvider` passou a usar o client de busca estático
  (`search={{ options: { type: "static" } }}`), que baixa o índice e pesquisa
  diretamente no navegador.

### Botão "Instalar agora" invisível no CTA

A variante `outline` do componente `Button` define `bg-background` (branco no tema
claro). Sobre o gradiente do bloco CTA, isso resultava em um botão branco com texto
branco — o texto só aparecia no hover. Adicionado `bg-transparent` ao botão, deixando
o gradiente aparecer atrás do texto.

## 📦 Versão

Versão sincronizada em web (`package.json`, badge da home) e CLI Python
(`pyproject.toml`, `maes/__init__.py`): **1.1.2 → 1.1.3**.
