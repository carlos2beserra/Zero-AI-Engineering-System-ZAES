## Comandos Principais

| Comando                | O que faz                                                                          | Precisa de API key? |
| ---------------------- | ---------------------------------------------------------------------------------- | ------------------- |
| `maes init`            | Cria scaffold `.maes/` e instala agentes externos                                  | Não                 |
| `maes sync`            | Compila contexto e gera adapters de IDE                                            | Não                 |
| `maes validate`        | CI gate — exit 1 se contexto inválido                                              | Não                 |
| `maes audit`           | Auditoria determinística com score 0–100                                           | Não                 |
| `maes doctor`          | Verifica instalação e configuração                                                 | Não                 |
| `/maes-analyze`        | Agente externo que popula `context/inferred/`                                      | Não                 |
| `/maes-context-add` | Agente externo que extrai regras de texto/arquivos e roteia para `context/human/*` | Não                 |
| `/maes-eval`           | Agente externo: LLM-as-judge que mede ganho com vs sem contexto MAES               | Não                 |

## Adapters Gerados

Após `maes sync`, o contexto compilado é exportado automaticamente para todos os assistentes de IA instalados no repositório:

- `CLAUDE.md` — carregado automaticamente pelo Claude Code
- `.cursor/rules/` — carregado automaticamente pelo Cursor
- `.windsurfrules` — carregado automaticamente pelo Windsurf
- `.github/copilot-instructions.md` — carregado automaticamente pelo GitHub Copilot

O mesmo contexto, compilado uma vez, serve a todos os assistentes sem configuração adicional por ferramenta.
